# PLANET PHONE — Storefront E-Commerce & Catalogue WhatsApp

Storefront e-commerce et catalogue interactif pour **PLANET PHONE**, boutique spécialisée en smartphones, montres connectées et accessoires située à **Bazar Dubai, Rue Frères Boussendalah (La Cité Ouest), Bouira**.

---

## 📱 Aperçu & Fonctionnalités

- **Design System Swiss Hardware Grid (Anti-AI-Slop)** :
  - Palette sobre et percutante : Blanc `#FFFFFF`, Gris technique `#F8FAFC`, Bordures nettes `#E2E8F0`, Rouge signature storefront `#D9232E`.
  - Typographie moderne : *Plus Jakarta Sans* & *Inter* pour les spécifications techniques et prix en Dinar Algérien (DA), avec support bilingue *IBM Plex Sans Arabic*.
- **Barre de Navigation (Navbar)** :
  - Logo géométrique avec cadre smartphone rouge.
  - Recherche instantanée multi-champs (modèle, marque, spécifications, couleur).
  - Accès direct WhatsApp (`0550 15 12 93`), Instagram (`@planet_phone10`) et Facebook (`PlanetPhonee`).
- **Hero Section Mobile-First** :
  - Titre percutant & badges de garanties (*Neuf Scellé*, *Cabas Garanti*, *Smart Watches*, *Services Ooredoo*).
  - Boutons d'action : « Explorer le Catalogue » et « Estimer une Reprise ».
  - Fiche produit vedette avec grille technique et commande WhatsApp.
- **Catalogue & Rayons In-Store (12 Références Réalistes DZ)** :
  - Rayons : **Apple**, **Samsung**, **Redmi**, **Realme**, **Smart Watch**, **Accessoires**.
  - Filtres par état : *Neuf Scellé*, *Cabas Garanti*, *Occasion Certifiée*, et disponibilité *🟢 En Stock Bouira*.
  - Tri par pertinence, prix croissant/décroissant, nouveautés.
- **Fiche Produit (ProductCard) & Modale de Commande (OrderModal)** :
  - Badges d'état et « Garantie Magasin ».
  - Sélecteur de capacité/stockage et pastilles de couleurs réelles.
  - Génération de messages WhatsApp pré-remplis avec détails du produit, variante et prix en DA.
  - Bouton d'appel direct vers le magasin.

---

## 🛠️ Stack Technique

- **Framework** : [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/) (Strict Mode)
- **Bundler & Outillage** : [Vite 5](https://vitejs.dev/)
- **Styles** : CSS Modules (Scoped, Zero-runtime, Zero dépendances inutiles)
- **Icônes** : SVG inline ultra-légers et réactifs

---

## 🚀 Installation & Démarrage

```bash
# Cloner le dépôt
git clone https://github.com/Guettaf-hossam/phone-store.git
cd phone-store

# Installer les dépendances
npm install

# Lancer le serveur de développement local
npm run dev

# Vérification TypeScript
npm run typecheck

# Compiler pour la production
npm run build
```
